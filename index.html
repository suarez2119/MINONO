¿Cómo hacer un pedido?

1. Elige

Busca en la carta de bebidas, jugos, cookies, salados y dulces. Ves el precio de cada producto.

2. Personaliza

Escoge el tamaño, el tipo de leche, el azúcar y los extras. El precio se actualiza solo.

3. Confirma

Revisa tu carrito, completa tus datos y recibe un código único para tu pedido.

4. Sigue tu pedido

Mira si está pendiente, en preparación o listo. El pago se hace con el personal al recogerlo.
